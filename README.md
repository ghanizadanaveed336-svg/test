# Modern Dashboard App

This repository now contains a complete C# WPF application with a modern dashboard-style UI.

## Project structure
- `src/ModernDashboardApp/` — application source code
- `ModernDashboardApp.sln` — Visual Studio solution

## Run it
1. Open `ModernDashboardApp.sln` in Visual Studio 2022.
2. Restore NuGet packages.
3. Set the startup project to `ModernDashboardApp`.
4. Press F5 to run.

## Features
- Modern dark glassmorphism dashboard UI
- Dashboard summary cards
- Task list with progress bars
- Team activity panel
- Search and quick action controls
- Clean MVVM-style separation

## Tech stack
- .NET 8
- WPF (Windows desktop UI)
